# The Toolshed

> `FORM E&E-TOOLSHED` · A Perimeter Company · Do not enter the Toolshed.

A collection of utilities shared across all Edge & Edge perimeter services. Nobody is quite sure what is in the Toolshed. The Toolshed predates the perimeter. It was here when we arrived last Tuesday.

## Contents

The Toolshed contains tools. These tools are shared, in the sense that no single Subcommittee will admit to owning them. Each is:

- **Permissionless.** You may use any tool in the Toolshed. Nobody is stopping you. 🤷
- **Foundational.** Each tool is a building block, and not, we stress, the end tool.
- **Broadly rectangular.** Where applicable.
- **Load-bearing.** Removing any one tool causes the others to convene a Subcommittee.

## Usage

```toml
[dependencies]
toolshed = { git = "https://github.com/edgeandedge/toolshed" }
```

Add it to your project and the tools will become available, in the order in which they were requested, and in no particular order.

## A note on the Toolshed

Do not enter the Toolshed. The Toolshed is not to be approached, organised, audited, or — under any circumstances — refactored. The last entity to refactor the Toolshed was promoted to Keeper of the Firehose and has not been seen since.
